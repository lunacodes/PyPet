# PyPet - A Virtual Pet Game in Python

PyPet is a work-in-progress redesign of a game I started writing 11(?) years ago, inspired by a now defunct tutorial ([Create A PyPet tutorial](https://www.thinkful.com/learn/intro-to-python-tutorial/Creating-Your-Pypet)). Basically it's my own spin on something tamagotchi-esque.

I'm currently coding the Django backend, and will use React for the front-end.
